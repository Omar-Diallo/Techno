# 🟠 Power BI — Jour 1

> **Thème :** installer Power BI Desktop et découvrir l’interface.  
> **Objectif :** ouvrir Power BI Desktop, repérer ses principales zones et enregistrer un premier fichier de travail.

---

## 🎯 À la fin de ce cours, tu sauras

- vérifier si ton ordinateur peut utiliser Power BI Desktop ;
- installer l’application sur Windows ;
- reconnaître les vues Rapport, Données et Modèle ;
- repérer le ruban, le canevas et les panneaux principaux ;
- enregistrer un fichier `.pbix`.

## 1. Power BI Desktop, c’est quoi ?

**Power BI Desktop** est une application de Microsoft qui permet de se connecter à des données, les préparer, les organiser et créer des rapports interactifs. Les rapports sont généralement enregistrés dans des fichiers `.pbix`.

> **À savoir :** Power BI Desktop est destiné à Windows. Si tu utilises un Mac ou un Chromebook, tu peux envisager une machine virtuelle Windows ou un ordinateur Windows pour suivre ce cours pratique.

## 2. Installer Power BI Desktop

Microsoft propose deux méthodes principales : l’installation depuis le **Microsoft Store** ou le téléchargement direct depuis son centre de téléchargement. Microsoft recommande généralement la version 64 bits pour le téléchargement direct. [web:225]

### Méthode A — Microsoft Store

1. Ouvre la page officielle de Power BI Desktop dans le Microsoft Store.
2. Clique sur **Installer**.
3. Attends la fin de l’installation, puis ouvre l’application depuis le menu Démarrer.

Cette méthode permet à Microsoft Store de gérer l’installation et les mises à jour de l’application. [web:225]

### Méthode B — téléchargement direct

1. Ouvre la page officielle de téléchargement Power BI Desktop de Microsoft.
2. Clique sur **Télécharger**.
3. Choisis la version correspondant à ton système ; Microsoft indique que la version 64 bits est recommandée dans le parcours de téléchargement.
4. Lance le fichier téléchargé et suis les étapes de l’installateur.
5. Ouvre Power BI Desktop depuis le menu Démarrer. [web:223][web:225]

### ⚠️ Télécharge uniquement depuis Microsoft

Évite les sites de téléchargement non officiels. Pour une installation sur un ordinateur professionnel ou scolaire, vérifie d’abord si l’installation est autorisée par l’administrateur.

## 3. Premier démarrage

Au premier lancement, une fenêtre d’accueil ou des liens vers des ressources d’apprentissage peuvent apparaître. Tu peux les consulter ou les fermer pour accéder à l’espace de travail.

Avant de continuer :

- vérifie que Power BI Desktop s’ouvre sans message d’erreur ;
- repère la barre de menus et le ruban en haut ;
- garde les noms des éléments ci-dessous en tête : **Rapport**, **Données**, **Modèle**.

## 4. Découvrir l’interface

### A. Le ruban

Le **ruban** se trouve en haut. Il regroupe les commandes principales, comme obtenir des données, transformer des données, ajouter des visuels ou gérer le modèle.

### B. Les vues à gauche

Selon la version de Power BI Desktop, tu peux trouver plusieurs vues dans la barre de navigation à gauche :

| Vue | À quoi elle sert |
|---|---|
| **Rapport** | Construire les pages du rapport et placer les visualisations sur le canevas. |
| **Données / Table** | Examiner les lignes et colonnes des tables chargées. |
| **Modèle** | Voir et gérer les relations entre les tables. |
| **Vue de requête DAX** | Écrire ou examiner des requêtes DAX, si cette vue est disponible dans ta version. |

Microsoft décrit les vues Rapport, Données et Modèle comme des espaces distincts pour créer les visuels, consulter les tables et examiner les relations. Les options disponibles peuvent varier selon la version. [web:227][web:228][web:229]

### C. Le canevas de rapport

Dans la **vue Rapport**, la grande zone centrale est le **canevas**. C’est là que tu disposeras plus tard les graphiques, cartes, tableaux et indicateurs. [web:227][web:230]

### D. Les panneaux à droite

Selon la version et la configuration de l’interface, tu peux voir des panneaux permettant de choisir les visualisations, consulter les champs de données et appliquer des filtres. Ces panneaux servent à construire et mettre en forme le rapport. [web:229][web:230]

> **Astuce :** si un panneau n’apparaît pas, ne panique pas. L’interface peut évoluer entre les versions et certains panneaux peuvent être masqués. Cherche les options d’affichage ou les volets dans le ruban.

## 5. Premier exercice : créer ton fichier de travail

1. Lance Power BI Desktop.
2. Dans l’accueil, choisis un nouveau rapport si nécessaire.
3. Repère la **vue Rapport** et le canevas vide.
4. Clique sur **Fichier → Enregistrer sous**.
5. Crée un dossier de cours, par exemple `03_Power_BI/fichiers_pbix/`.
6. Enregistre sous le nom `PowerBI_Jour_01_Interface.pbix`.
7. Clique sur les vues **Rapport**, **Données** et **Modèle** si elles sont visibles ; note ce que tu observes.

À ce stade, il n’est pas nécessaire d’importer de données. Le but est seulement de repérer l’environnement et d’enregistrer ton premier fichier.

## 🧠 Vocabulaire à retenir

- **Rapport** : ensemble de pages présentant des données sous forme de visuels.
- **Canevas** : surface où tu places les visuels.
- **Table** : données organisées en lignes et colonnes.
- **Modèle** : tables et relations utilisées pour analyser les données.
- **Fichier `.pbix`** : fichier de travail Power BI Desktop.

## ⚠️ Problèmes fréquents

- **L’installation échoue :** vérifie que tu utilises une source Microsoft officielle et que ton compte ou ordinateur autorise l’installation.
- **Tu ne trouves pas une vue :** cherche les icônes dans la barre latérale gauche ; leur présentation peut varier selon la version.
- **Tu ne vois pas les panneaux à droite :** vérifie les options d’affichage/volets dans le ruban.
- **Tu as fermé sans enregistrer :** utilise régulièrement **Ctrl+S**.
